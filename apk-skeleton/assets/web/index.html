キャッシュ / 保存データ

キャッシュとは、表示を速くするために端末へ一時的に置いているデータ（画像・アイコン・タイムラインの控えなど）です。KoeTomo+ はできるだけキャッシュを使わない設定で動いていて、上限（画像など約16MB）を超えた分は自動で捨てています。それでも気になるときは、下のボタンでいつでも全部消せます。

消えるもの：画像・アイコンの一時ファイル、タイムラインの表示用の控え、既読・いいねの記録。
消えないもの：ログイン情報、保存したアカウント、フォント・テーマなどの設定、下書き、BANリストの設定。
削除しても失われるデータはありません。次の表示が一度だけ少し遅くなるだけです。

制限にかかった記録

投稿・枠作成などがサーバー側の制限で弾かれたとき、その時刻・前回成功からの秒数・サーバーの文言を記録します（この端末内だけ）。公式アプリにもアプリ内のクールタイムは無く、制限はサーバー判定のみです。

保存(ダウンロード)

保存ボタンを押したときに形式をきくかどうかと、保存先フォルダをここで決められます。

・KoeTomo フォルダ（おすすめ）… 画像は 画像/KoeTomo、音声は 音楽/KoeTomo。ギャラリーや音楽アプリの一覧にそのまま出るので、いちばん見つけやすいやり方です。
・ダウンロード内の KoeTomo 専用フォルダ… ダウンロードの中に KoeTomo フォルダを作り、音声は Audio、画像は Images へ自動で振り分けます。1か所にまとめたい人向け。
・ダウンロード直下… 他のアプリと同じ場所にそのまま置きます。

オフにすると、下で選んだ形式ですぐ保存します。オフのままでも保存ボタンを長押しすればその場で形式を選べます。

保存が終わると、保存先つきの通知が出ます。

判定は量産型アイコン名・「単語＋3桁数字」の名前・フォロー0などの特徴からの推定です。マークをタップすると理由が出て、業者垢だと確認できたら「BANリストに申請する」で共有BANリストに申請できます（承認制）。

必須条件（16文字ランダムのアイコン名・フォロー/フォロワー/友達/いいねが全て0・自己紹介なし・年齢確認なし）をすべて満たし、さらに「単語＋3桁数字」の名前・既知botとID連番・直近1時間に5件以上投稿などの加点が一定を超えたときだけ申請します。判定と証拠はアプリがAPIから取り直して作るので偽造できません。自動で申請するだけで、ブロックはしません（ブロックは管理者が承認してから）。申請は30秒あけて1時間3件・1日10件まで、同じ相手は1回だけです。

タイムラインで is_explicit 系フラグが立っていた投稿のログです。空の場合はサーバー側が該当フラグを送ってきていません。

共有BANリスト連携

コミュニティで承認されたbot・スパム等のユーザーを、koetomo本体のブロック機能で自動的にブロックします（いつでも設定画面から解除可）。通報は、あなたがプロフィールで手動1タップした時だけ送られます。自動での一斉通報はしません。

このアプリで「できないこと」(移植不可)

下記はAPIではなくスマホ側の仕組みが必要なため、非公式クライアントでは実現できません。

・コイン/サブスクの購入 … Google Play課金が必要（残高表示・消費は可能）
・プッシュ通知の受信 … 公式のFirebase鍵が必要（代わりにアプリ内で定期取得）
・SMS/電話番号認証の一部 … 端末側の認証が絡む場合
・端末認証・改ざん検知が要る機能 … 公式サーバーが弾く場合あり
・「マッチング」「dive拡張」など用途未確定の機能 … 暫定実装(動かない場合あり)
